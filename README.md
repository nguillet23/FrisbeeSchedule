# FrisbeeSchedule

A web app designed to help my friends know my frisbee schedule and find times when we can practice together.

The app allows users to:

* View my weekly frisbee schedule.
* See available practice times.
* Find overlapping availability with other players.
* Check who is available during those times.

## Features

* Weekly calendar view
* Team availability tracking
* Availability overlap detection
* Admin schedule management
* Supabase database integration
* Secure admin login

## Purpose

This project was created to make scheduling frisbee practices easier by showing when people are available and helping the team find good times to play.
